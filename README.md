A web-based student skill-sharing platform developed using Python and Flask, with SQLite as the database. SkillSwap connects students who want to learn new skills with peers who can teach them. Users can create profiles, list skills they offer or want to learn, discover other members, send and manage skill exchange requests, and share reviews and ratings after completing an exchange.

Key Features:
- User registration and secure login.
- Student profile management.
- Add and delete skills.
- Categorize skills as Offer or Want.
- Search and discover other students by skills.
- Send and manage skill exchange requests.
- Accept, decline, and complete exchanges.
- Submit ratings and reviews after exchanges.
Technologies Used:
- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- Werkzeug (Password Hashing)
